#18T1 概念卡 + T6 辨析准备律（law of readiness）最容易错 · 定义题 + 例子题双角度
一句话说人话学之前你有没有「想学」的状态？猫饿了才想开笼子 —— 这叫准备律，说的是动机。老师的启示：不能搞突袭。

准备律 = 学习前的预备性反应 / 预备定势（生理 + 心理）→【动机范畴】

打个比方

就像跑步前的「各就位 — 预备」：身体蹲好了（生理）、心里想着「我要冲」（心理）—— 枪一响就能跑。没「预备」直接鸣枪，人还在系鞋带，肯定跑不好。老师举的两个例子：

  • 生理：猫饿了 → 想觅食 → 有开笼子的动机。你没吃饱饭就不想听课，吃饱了就能积极干别的事（62:07）。
  • 心理：老师提前说「今天讲两个半小时、讲到哪儿」，你心里有准备；「想听明白这个课，我可以上岸」—— 也是动机（57:16）。

不管生理还是心理，落脚点都是动机。所以准备律属于动机范畴。

回到考试用词（S023）
  • 定义：学习前预备性反应 / 预备定势（生理 + 心理）→【动机范畴】。例：猫—饥饿。
  • 细节考点（原句）：桑代克讲的准备不是指学习前的知识准备或成熟方面的准备，而是指学习者在学习开始时的预备定势，属于动机范畴。
  • 启示：不能搞突袭。老师：「我们今天 7 点上课，那你 7 点前你要做好各种准备啊 —— 提前预习、上好厕所、吃好饭，然后可以更积极地去听课。」
⚠️ 历年最容易栽的坑 —— 老师说「打起精神，仔细听」（58:02-61:43）

那句「不是知识准备、不是成熟准备」怎么考？要分两个角度解题：

角度题怎么问怎么答为什么
① 定义角度「桑代克提出的准备律是指学习前的知识或成熟方面的准备」（判断）错，不等同老师：「并不是说知识准备、成熟达不到准备律的效果，只是说桑代克没从这个角度来说，他强调的角度是动机范畴」
② 例子角度「老师让学生预习 / 复习旧知 / 预设问题激发兴趣」属于哪个律？准备律预习、复习、查资料 —— 最终落脚点都是引起学习动机、提高学习积极性；能激发动机的都算准备律

老师的推理链（58:26-59:54）：知识准备、成熟准备 → 能不能激发学习动机？能 → 激发了动机 → 属不属于准备律？属于。「你预习过了，你就觉得我接下来就要学这个，我心里是有准备的，我想把它搞明白 —— 有想学的动机。复习相关点，旧知识和新知识有联系，你就会好奇怎么联系、怎么区分 —— 也会产生学习的欲望。」

教材原文（S032 右下截图，老师用来佐证「例子角度可以算」）

（一）准备律（law of readiness）：准备律是指当个体心理和生理上有准备时，所表现的行为通常是令人满意的。正如，体育竞技比赛之前的热身运动。反之，要是毫无心理和生理上的准备，学习的结果往往不尽如人意。同理，当个体是有备而来，却不让他有所表现，也会产生挫折感。个体在学习上的准备工作包括两方面：一为身心基础，即个体的发展阶段上，例如学习武术，那首先要考查他的身体发育是否正常，四肢、关节是否敏捷，反应是否灵活，眼手是否协调；二为学习动机，求知欲和好奇心是提高学习动机、增进学习的效果的重要因素……以课题激发学习动机，引导学生进入学习状态。一般引起学习动机，包括复习上次所学内容，以及有关资料，以便对新教材产生兴趣，从而调动了学习的积极性。

老师的解读（76:34-77:19）：「身心基础」就是生理层面 —— 身体倍儿棒你学起来才积极，「身残志坚腿脚不利索你说去学武术，我不想学」，没动机；「学习动机」这一段直接说了复习、查资料都是为了对新教材产生兴趣 —— 所以预习/复习 → 激发动机 → 符合准备律。

老师板书（S029 / S032-S033 蓝绿笔）

S029 准备律旁写：「→ 定义：≠」「→ 例：预习、…」，右侧竖写「知识准备 · 成熟 → 动机范畴 → 积极性」，还有「×知识 · 成熟」。S032 左下三条结论（第一条红、后两条青绿）：① 桑代克的准备 ≠ 学习前的知识准备或成熟方面的准备；② 桑代克的准备 → 预备定势，属于学习动机范畴（黄底高亮）；③ 预习/复习有关等 → 调动学习积极性 → 符合准备律。教材截图上圈了「身心基础」并旁注「生理」，末段的「复习」「有关资料」「产生兴趣」都被圈了。

关键词
预备性反应预备定势生理 + 心理动机范畴≠ 知识准备 / 成熟不能搞突袭law of readiness
记忆锚点
各就位—预备 = 动机；定义题说「不等于」，例子题说「预习复习都算」
出题人怎么考
判断「准备律指知识/成熟准备」→ 错；单选「预设问题 + 预习」→ 准备律；判断「复习和引导帮助回忆已有知识符合准备律」→ 对；单选「准备律与现代学习心理学中的（ ）相一致」→ 动机原理。
#19T1 概念卡练习律：应用律 / 失用律例子分析（看有没有反馈来区分效果律）
一句话说人话连好的线，常用就越结实，不用就松掉 —— 熟能生巧、用进废退。

练习律 = 已形成的联结，重复反应 → 联结↑；不重复 → 联结↓

打个比方

一条小路，天天走就越走越宽越好走（应用律）；半年不走就长满草找不到了（失用律）。猫也是 —— 「如果它只是一次开笼子，它会那么快就学会吗？不会，它一定是反复开笼子，最后才减少错误」，熟能生巧。

回到考试用词（S023）
  • 形式一 应用律：常用（练习）→ 联结↑
  • 形式二 失用律：不常用（不练习）→ 联结↓
  • 老师总结：练习律就是「用和不用的关系，熟能生巧，有点用进废退的意思」（64:19）。
  • 启示：在学习过程中以及学习结束后，都应该不断地加强练习。
坑 · 练习律 vs 效果律

题干只说「反复练、练不同类型、每天听说」而没提结果好坏 → 练习律；一旦出现「表扬 / 批评 / 成绩 / 反馈」→ 效果律（下一张卡）。老师在勾股定理题上专门说：「这里边给反馈了吗？光强调练习的角度，并没有进一步强调得到什么样的结果」（68:54）。

老师板书（S029 蓝绿笔）

练习律旁写「用 or 不用」；圈应用律的「联结↑」，失用律的「不常用」「联结↓」下划线；从练习律拉弯箭头指到启示句。

关键词
重复反应应用律失用律熟能生巧用进废退学习结束后也要练
记忆锚点
小路天天走变宽，半年不走长草
出题人怎么考
「计算不同类型的直角三角形」「三天不听耳生三天不读口生」→ 练习律（只强调练，没给反馈）。
#20T1 概念卡 · ★最重要效果律：满意律 / 烦恼律例子分析「偏好效果律」· 最重要的学习定律
一句话说人话练完了有没有人告诉你「对了 / 错了」？好结果让你更愿意做，坏结果让你不想做 —— 反馈决定一切，所以它最重要。

效果律 = 正或负的反馈 → 加强或减弱联结

打个比方 · 老师的驾照故事（64:42-65:25）

「我之前去考驾驶证的时候去练车，练车的过程中发现一个很痛苦的点：我怎么练，教练都不告诉我正确与否，我就越练越懵。所以我急需反馈，我就去问这个问那个，得到了反馈，进步就特别快。」

→ 光有心理准备、光练，但不告诉你对错，你也没办法成功。所以效果律最重要，练习律和准备律都从属于它（没它的存在，它们意义也不大）。

回到考试用词（S023）
  • 形式一 满意律：满意后果 → 行为↑。猫逃出笼子获得食物 → 下次继续。「你每次练，加油你最棒、你真优秀 —— 情绪价值、各种奖励满满当当，你愿不愿意做？愿意，行为频率提得高高的。」
  • 形式二 烦恼律：烦恼后果 → 行为↓。「一学习我就骂你、否定你、各种批评打压 —— 行为频率就下降。」猫出去没有鱼，「甚至不是鱼是坨狗屎，它可能也不愿意去做了」。
  • 启示：使学生的学习达到自我满意的积极结果，防止一无所获的消极结果。
  • 效果律是最重要的学习定律。准备律和练习律是效果律的附律 / 从属律。（必背，S023 右侧红括号）
坑 · 反馈从哪来（蒙眼画线实验，80:36-82:24）

桑代克让被试蒙上眼睛练画 4 英寸线段，3000 多次毫无进步 —— 为什么？没有反馈。老师追问：反馈可以怎么来？① 自己看（不蒙眼就能看到画歪了、画长了）；② 别人说。这道题选 C「被试不知道自己的练习结果」而不选 D「主试未评价」—— 因为 C 把两种来源都包括了，更全面；D 只说了别人没告诉，忽略了「他自己也看不到」，片面。

老师板书（S029 / S040 蓝绿笔）

S029：圈「反馈」和「获得食物」，右栏「最重要」「准备律和练习律」「效果律」下划线。S040（蒙眼题）：顶栏写「反馈」；C 项旁写「反馈」；右下画分叉「没有反馈 → 自己看（圈）/ 别人给（勾）」，两支之间写勾和加号；C 项右上还有一支「眼看可以… / 别人说—可以…」（末字认不准）。

关键词
正或负的反馈满意律烦恼律最重要附律 / 从属律自我满意的积极结果防止一无所获
记忆锚点

#22T2 对比 + 评价动物 vs 人的学习 · 评价 · 局限判断题
一句话说人话猫是瞎试出来的（盲目），人进笼子会先看再想（有意识）。桑代克的理论是教心史上第一个比较完整的学习理论，但早期忽视了人的认知和目的性。

动物 VS 人类 + 评价

回到考试用词（S021 / S019）
  • 动物学习 → 盲目的；人的学习 → 有意识的（动物的学习无须以观念为媒介）。这是他后来的研究得出的；最早的研究是用动物做的。
  • 评价①：联结—试误说是教育心理学史上第一个较为完整的学习理论。
  • 评价②：它的提出，对于教育心理学成为一门独立学科是有促进意义的（他正式开创了实验室、用数据研究出科学的内容）。
老师怎么讲「人不一样」（70:02-71:08）

「你想想你把人关到笼子里，如果他不小心按压到杠杆开了门，他下次还会盲目尝试吗？不会了吧。再怎么不长脑子的人，进去了也会尝试去开门，尝试到了、得到结果了，下次就直接会开了。人进去可能会先观察环境、去思考，然后尝试，也不会有那么多错误的过程。所以他认为人的学习是有意识的。」—— 老师说这句「一般考判断」。

局限（老师延伸，74:02-74:45）

桑代克早期研究忽略了认知、忽视了人学习的目的性。「即使对于这个猫来说，猫真的就一点意识都没有吗？不见得。但桑代克的实验具有它的局限和片面。这就是早期研究为什么得到诟病、甚至批判的一个原因 —— 很多理论站在当时的角度上并不够完善。」
