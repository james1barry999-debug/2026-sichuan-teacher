#24T2 左右对比无条件反射 vs 条件反射例子分析第一步：先天 or 后天
一句话说人话天生就会的叫无条件反射（吃东西流口水）；后天学出来的叫条件反射（听到铃声就上课）。判断只问一句：我天生就会吗？

老师怎么定义这几个词（95:10-97:24）
  • 什么叫无条件刺激？「你就理解为能引起无条件反应的刺激」—— 食物能让你天生流口水，食物就是无条件刺激；「不分泌唾液就噎死了呀，这需要学习吗？不需要。」
  • 同理，引起条件反应的刺激叫条件刺激（去年末考过一回）。
  • 「听到铃声就上课」是后天的 —— 「孩子一出生听到铃声就跑到教室坐好？怪吓人的。」
  • 「闹铃响就起床」有点争议：被声音吵醒是一回事，建立了「闹铃 = 该起床」的意识是另一回事，解读不同答案会不同。「这种考察的可能性不大，如果考的话他会说得比较明确。」
  • 无条件反应和无条件反射「有的时候会混用，不用死抠区别」—— 产生了无条件反应就代表有了无条件反射。

#25T5 实验卡 · 五行表狗进食摇铃实验：一级 → 二级实验流程是第一个考点
一句话说人话铃声本来没用；跟食物一起出现 N 次后，光听铃也流口水 —— 铃声「上位」了。再让灯光跟铃声一起出现 N 次，灯光也上位。

条件反射建立过程（S049–S050 五行表）

打个比方 · 老师的「闺蜜 / 蹭流量」（101:19-102:29）

「铃声反复跟食物碰瓷，两个人总是在一起，仿佛沾染了一些流量一样。就跟两个闺蜜似的，他俩总一起出现 —— 当树袋熊单独出现的时候，别人就会问他：哎，娃哈哈呢？你们俩不总一起出现吗？」所以单独给铃声，狗就默认「食物到位了」，也会流口水。

#建立过程身份反射变化
1食物 → 流口水无条件刺激 → 无条件反应无条件反射（先天）
2食物 + 铃声 → 流口水，×N 次无条件刺激 + 中性刺激 → 无条件反应（此时流口水仍是因为食物，铃声不起作用）↓
3铃声 → 流口水条件刺激 → 条件反应条件反射 1（后天）
4铃声 + 灯光 → 流口水，×N 次条件刺激 1 + 中性刺激 2 → 条件反应↓
5灯光 → 流口水条件刺激 2 → 条件反应 2条件反射 2
两个「身份转变」（老师反复问）
  • 铃声：中性刺激（不起作用，「特别中性的名称」）→ 条件刺激。
  • 流口水：虽然都是流哈喇子，起初是无条件反应（因为食物），后来是条件反应（因为铃声）—— 引起的对象不一样了。
  • 第一次结合时狗流口水，「是因为食物还是因为铃声？食物。他顶多是越吃越愉快，还没建立起来呢」。
二级（105:29-107:22）

「这时候铃声是不是跟食物一样厉害了？既然铃声现在跟食物一样牛，那我能不能在铃声的基础上再做一个实验？」把铃声和灯光结合 N 次 → 单独给灯光也流口水 → 灯光也变成条件刺激。「相当于把食物替换成了铃声，但名称一直跟着变。」1–3 步叫一级条件作用，3–5 步叫二级条件作用，也叫高级条件作用。「能不能建立三级、更高的？只要狗没问题就可以，但到后期狗会有点问题 —— 三级勉强可以，四级就更难了。」

#26T7 口诀锚图钥匙① 建立顺序：要么先中性，要么和中性同时理论识记 · 2017 真题
一句话说人话铃声要当「开饭预告」，就必须在食物之前或同时响；等狗吃完了再摇铃，它不知道你在干嘛。

怎么结合才能让铃声起作用（103:13-105:29）

打个比方 · 鸡场打铃（老师原例）

「有人养鸡场特别多的鸡，然后就会打铃、摇铃或者放个音乐，就代表马上到点吃饭了，它们就聚集在一起了。所以这个铃声就相当于预告。」预告必须在前面 —— 「你都吃食物、都流完哈喇子了，我再给你铃声，咋的？跳个舞消化一会儿啊？没用。」而且要紧接着：「你给他响个铃声，放半天了再给食物，他也不知道他俩有联系啊，这个预告还有啥作用？」

回到考试用词（S052–S058 老师手写，S060 印刷口诀）
  • 一级建立：无条件刺激 和 中性刺激 ⇒ 同时；或 先中性刺激，紧接着无条件刺激。
  • 二级建立：条件刺激 和 中性刺激 ⇒ 同时；或 先中性刺激，紧接着条件刺激（灯光成了铃声的预告，铃声又是食物的预告）。
  • 合成一句口诀：要么先中性，要么和中性同时。「考试都是考顺序。」
  • ❌ 先给无条件刺激（先喂食）再给中性刺激（再摇铃）—— 不行。
