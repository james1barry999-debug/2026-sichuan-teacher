#33T2 左右对比 · 拔高经典性条件作用 vs 操作性条件作用溯源拔高 · 4 道判断
一句话说人话巴甫洛夫是「先给刺激再有反应」（S→R）；桑代克和斯金纳是「先做动作再得结果」（R→S）。方向相反，但骨子里都是把 S 和 R 连起来。

三条结论（S086 原句）

回到考试用词
  1. 桑代克和斯金纳的学习理论从性质上看都属于操作性条件反射。（猫按杠杆得鱼、小白鼠按杠杆得食丸 —— 都是先做动作再得结果，R→S）
  2. 经典性条件理论和操作性条件作用理论的实质相同（S-R / 刺激和反应的联结）。
  3. 经典条件反射的建立过程与操作条件反射的建立过程存在差异（S→R vs R→S）。
打个比方

两座桥都连着「刺激」和「反应」两岸（实质相同）；但巴甫洛夫的桥是从 S 岸往 R 岸走，桑代克、斯金纳的桥是从 R 岸往 S 岸走（建立过程不同）。考试问「实质」→ 相同；问「建立过程」→ 有差异。问什么答什么，别混。

坑 · 「行为前的强化」

操作性条件反射强调的是行为之后的强化：你先做出行为，然后才给强化（食丸）。所以「操作性条件反射理论强调行为前的强化」→ 错。

斯金纳那一页（S087，只闪过，老师没讲，不展开）

幻灯片上写着：操作性（工具性）条件作用理论 · 迷箱实验 / 斯金纳箱 / 小白鼠按杠杆 · 学习实质：反应概率的变化，强化是增强反应概率的手段 · 两种行为：应答性行为（S→R）和操作性行为（R→S）· 装置：扬声器、信号灯、操纵杆、食槽、电击网；按操纵杆 → 获得食丸。—— 老师说明天讲，本手册只照抄页面，不添加讲解。

巴甫洛夫笔记梳理（S084 / S089 老师最后过的一遍）

一、学习的定义
凭借 经验或练习 产生的 行为或行为潜能 的比较 持久 的变化。不算学习：膝跳反射 / 疲劳 / 暗适应。
二、学习的分类
奥苏贝尔 · 学习方式：接受（结论方式、效率高、忽视主体）/ 发现（不直接呈现、效率低、学生为主体）；新旧关系：机械（×联系）/ 有意义（√联系，非人为、实质性）。两维度 互不依赖、彼此独立，四种学习 无高低之分，奥苏贝尔提倡 有意义的接受学习。编口诀 / 谐音 = 人为赋予 → 机械。顺序：先机械后有意义。
加涅 · 学习结果（无高低）：言语信息、智慧技能、认知策略、态度、动作技能（口诀 颜值态动人）；学习水平（从低到高）：信号 → 刺激反应 → 连锁 → 言语联想 → 辨别 → 概念 → 规则 → 问题解决（口诀 心机所言别念这题）。信号 = 刺激在前；刺激反应 = 反应在前、一个动作；连锁 = 一串动作。
阿瑟雷伯 · 学习意识水平：内隐（不知不觉）/ 外显（有意识）。我国学者：冯忠良多了 社会/行为规范；潘菽版二拆出 动作技能、智慧技能。
三、四大流派
行为看 外在行为、认知看 信息加工（客观、单向）、建构看 个体与环境双向作用（主观）、人本看 情感与人际关系、人性本善。口诀：桑巴死板 · 苛曼不输加涅 · 健脾胃度 · 罗马人。实验：桑代克的猫 · 巴甫洛夫的狗 · 斯金纳的小白鼠 · 班杜拉的宝宝。
四、行为主义概述
创始人 华生（联结主义创始人 桑代克）；研究 外显行为；方法 实验法；核心 刺激—反应的联结 S-R（无箭头）；地位 第一革命、第一势力。华生的实验：小阿尔伯特 · 恐惧泛化实验。
五、桑代克 · 试误说（一实验三规律一评价）
实验：猫开笼取食（饿猫 / 迷笼 / 迷箱），前提猫要 饿（动机），方向 R→S 反应在前。学习实质 形成联结（刺激与反应）；建立 通过试误。
准备律 = 预备定势 → 动机范畴（≠ 知识准备 / 成熟，但例子题里 预习 / 复习 → 算准备律），启示 不能搞突袭；练习律 = 应用律 / 失用律（用 or 不用）；效果律 = 满意律 / 烦恼律（反馈），效果律最重要，另两条是附律。动物学习 盲目，人的学习 有意识。评价：第一个较为完整的学习理论 · 促进教心独立。
六、巴甫洛夫 · 经典性条件作用（一实验二反射二规律）
实验：狗进食摇铃，方向 S→R 刺激在前。铃声：中性刺激 → 条件刺激。一级跟 无条件刺激 结合；高级跟 条件刺激 结合。建立顺序：要么先中性，要么和中性同时。拔高：中性刺激一旦成为条件刺激，就可以 作为（替代）无条件刺激。
反射：无条件反射（先天本能）/ 条件反射（后天学习）。信号系统：第一 = 物理性，人+动物，无语言；第二 = 以语言为中介，人特有。三步：先天？有语言？是动物？。尝梅生津 = 本能；望梅止渴 = 字面第一 / 曹操说第二；杯弓蛇影 = 第一（不许加戏）。
规律：获得 = 无→有；消退 = 有→↓/无（光铃不给食）；泛化 = 相似刺激相同反应（分不清）；分化 = 相似刺激不同反应（分得清）；两者 互补。基础识记：最早提出「强化」的是 巴甫洛夫。
七、溯源
桑代克 + 斯金纳 = 操作性 R→S；巴甫洛夫 = 经典性 S→R；实质 相同（S-R 联结），建立过程 有差异。
