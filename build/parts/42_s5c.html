#29T2 左右对比钥匙③ 第一信号系统 vs 第二信号系统成语判断 · 易错重灾区
一句话说人话后天的条件反射分两种：靠「声光影电」这种具体东西引起的 = 第一（人和动物都有）；靠「语言」引起的 = 第二（人独有）。判断只问：有没有语言？

条件反射 → 大脑皮层功能 → 两套信号系统（S074）

第一信号系统第二信号系统

例子狗：铃声 → 流口水；人：铃声 → 回到教室坐好；声光雷电（老师说「声光影电」）谈虎色变、看到「虎」字就害怕、一想到测验就焦虑、司机看到红灯停车

老师 133:24：巴甫洛夫做实验时用他弟弟，「每次给食物给铃声，他弟弟听到铃声也可以流口水」—— 所以第一信号系统人和动物都有。

语言的几种形式（拓展，「不是让你做多选的」）
  • 口头语言：别人说给你听。老师例：「我今天吃了一个提拉米苏可好吃了，上面都是蓝莓，咖啡液泡的，有点苦涩但有些甜……同学听完了叭叭流口水」—— 刺激是通过说传给你的。成语：谈虎色变（谈论老虎 = 刺激，脸色变 = 反应）、谈梅生津。
  • 书面语言：写出来给你看。「我发微信描述小蛋糕多好吃，你口里生津」；看到「虎」这个字就害怕。
  • 内部言语：你脑子里在「说话」。「一想到测验就焦虑 —— 你大脑里不是个图片吧，是在说话吧，有文字有题。」
  • 交通语言（单独记，争议点大）：司机看到红灯停车。「为什么归到语言？因为我们从小学过红灯停绿灯行，红灯对我们有『停』这个意义。」
  • 其他：哑语、旗语等。

老师：「这块不是让你做多选的，每个老师讲的角度都不一样，是拓展延伸，重点看里边的内容。」

两条铁律 + 一条禁令
  1. 动物没有语言。「你叫狗的名字，狗摇尾巴，属于第二吗？不属于 —— 动物压根没有语言。如果它产生后天反应，那顶多只能是第一。」
  2. 看刺激怎么传递给你，不是看个体自己有没有讲话（157:10）：「你说这个人他个体在这叭叭讲话有用吗？没有用。要判断第一还是第二，是要看给他这个刺激是怎么传递的 —— 是通过语言给他的，还是通过一个图样给他的。」
  3. 不许加戏（156:06）：「题目没说你不许给我延伸。杯弓蛇影里传递给你的就是一个影子，有说话吗？没有。你不要在这说『哎呀我大脑里想到了蛇太可怕了』—— 那就叫加戏。有的同学就可喜欢自己编东西了。」

解题训练：如何判断第一 or 第二信号系统（S075 流程图 + 十例）

老师原话（138:18-139:04）

「第一个做题步骤是先判断这个是先天有反应还是后天有反应的 —— 因为很多题目涉及的是本能、不学而会。如果能判断是后天的反应，你要进一步判断有没有语言，有语言的是第二，没有语言的是第一。还有一个偷机取巧的方法：是不是针对动物 —— 如果是针对动物，后天的那只能是第一，不可能是第二。」

#31T2 左右对比规律① 获得 vs 消退识记 + 例子
一句话说人话获得 = 从没反应到有反应（无→有）；消退 = 光摇铃不给饭，久了狗就不理你了（有→无）。

获得与消退（S076 / S091）

回到考试用词
  • 获得：条件刺激（如铃声）反复与无条件刺激（如食物）相匹配，使条件刺激获得信号意义的过程 —— 条件反射建立的过程（无 → 有）。
  • 消退：在条件反射形成后，如果条件刺激重复出现多次而没有无条件刺激相伴随 —— 条件反应变弱，最终消失（有 → ↓ / 无）。
老师怎么讲（146:04-146:47）

「什么是获得？太简单了 —— 起初对铃声没反应，铃声和食物反复结合，对铃声有反应了，从无到有。什么是消退？给铃声，但我不给它食物，再给铃声也不给食物。时间够久了，狗也不傻 —— 你再给我铃声，我就不留哈喇子了，我不跟你玩了还不行吗？从有到少到无。」

老师板书（S080 → S091 紫色揭示）

S080 时「获得」框里出现「无→有」，消退框还空着；S091 消退框才填出「有→↓/无」。老师在「如铃声」「无条件刺激」「条件刺激」旁画了短线。

关键词
获得信号意义建立过程无 → 有没有无条件刺激伴随变弱 · 消失有 → 无
记忆锚点
获得 = 铃配饭有了；消退 = 铃不配饭没了
出题人怎么考
「条件反射建立的过程」→ 获得；「只给铃声不给食物反应消失」→ 消退。
#32T2 左右对比规律② 泛化 vs 分化例子分析为主 · 3 道题
一句话说人话泛化 = 分不清：给铃声流口水，给口哨也流。分化 = 分得清：铃声有饭、口哨没饭，练久了只对铃声反应。

泛化与分化（S081 / S082）—— 互补

回到考试用词
泛化分化
定义人和动物一旦学会对某一特定的条件刺激做出条件反应以后，其他与该条件刺激相类似的刺激也能诱发其条件反应通过选择性强化和消退使有机体学会对条件刺激和与条件刺激相类似的刺激做出不同的反应
解题关键相似刺激 → 相同反应（分不清）—— 对「相似」的反应相似刺激 → 不同反应（分得清）—— 对「差别」的反应
例子一朝被蛇咬十年怕井绳（蛇 / 绳分不清）；分不清相似的字；分不清勇敢和鲁莽；杯弓蛇影（弓影 / 蛇）；小阿尔伯特怕所有白毛分辨谦让和退缩；铃声给食、口哨不给 → 只对铃声反应
学习意义使我们的学习从一种情境迁移到另一种情境（语文课的高效学习法 → 英语课）对不同的情境作出不同的恰当反应，避免盲目行动（语文和英语毕竟不同）

两者互补：一个把好的迁移过去，一个做恰当区分 —— 合起来学习效果更好。「泛化、分化不是说一定是个不好的词，它是中性词，看怎么用。」

老师怎么讲分化怎么做出来（147:56-148:42）

「起初给铃声的时候给狗食物，但是给狗口哨的时候不给它食物。反复进行，时间久了，狗又聪明了、它又行了 —— 一有铃声明白要做反应，给口哨不反应了。这时候它能分清铃声和口哨了，叫分化。」

坑 · 「分得清分不清」够用吗？（148:42-149:04）

「很多同学用分得清分不清，百分之七八十的题都能做。但个别题目我还是希望你从定义角度解读 —— 看是不是相似刺激做相同反应（泛化）/ 不同反应（分化）。」例：「数学课上学会端坐，英语课也做出类似行为」—— 相似情境做相同反应 → 泛化；用分得清分不清反而不好判。

老师板书（S081-S082 紫笔）

泛化括注填「分不清」，空位填「相似」（对相似的反应），旁写「蛇、绳」；分化括注填「分得清」，空位填「差别」（对差别的反应），右上写「蛇√ 绳×」（能分清蛇和绳就是分化）。圈了「谦让 / 退缩」「盲目行动」「互补」，两个「情境」下划线。

关键词
相似刺激相同反应分不清选择性强化和消退相似刺激不同反应分得清迁移 / 恰当反应互补 · 中性词
记忆锚点
泛化 = 蛇绳分不清；分化 = 蛇√绳×；用定义「相同/不同反应」更稳
出题人怎么考
「数学课端坐英语课也端坐」→ 泛化；「类似刺激也能诱发」→ 泛化；「训练后仅对圆形反应」→ 分化（一定看到最后一句）。
