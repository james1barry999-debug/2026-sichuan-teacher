#27T6 场景辨析 · 拔高钥匙② 一级 vs 高级：看「跟谁结合」拔高题（进考场焦虑）
一句话说人话跟「天生就有感觉的东西」（食物）结合出来的 = 一级；跟「后天才有感觉的东西」（铃声）结合出来的 = 高级。做题要往上推：这个反应是跟谁绑出来的？

一级条件作用 vs 二级（高级）条件作用

回到考试用词（S070 提示 / S084 总结）
  • ① 一级条件作用：【先天】无条件刺激 和中性刺激结合 → 建立（跟无条件刺激联结建立）。
  • ② 高级条件作用：【后天】条件刺激 和中性刺激结合 → 建立（跟条件刺激联结建立）。
  • 老师 110:16：「做题当中一级、二级怎么区分？你就要推导它整个建立的过程，看它结合的是无条件这种先天有感觉的东西，还是结合的后天有感觉的东西。看他跟谁搭伴儿，碰瓷的谁。」
老师总结的三个考点（115:58-117:04）

「① 整个实验流程记住了吗？② 建立的顺序那个口诀 —— 要么先中性，要么和中性同时；③ 高级条件作用中，谁替代了无条件刺激？条件刺激。这三个都看明白了，前面这个实验你就没问题了。」

拔高判断 · 「替代性无条件刺激」（S051 右栏，老师 113:39-115:34）

原句：在条件作用形成以后，条件刺激可以像无条件刺激一样诱发出有机体的反应。从这种意义上说，条件刺激似乎成了一种「替代性」的无条件刺激。拔高说法：中性刺激一旦成为条件刺激，就可以作为无条件刺激。

老师翻译：「以前食物能单独引起流口水，现在铃声也能；以前用食物这个无条件刺激和别人结合，现在用铃声这个条件刺激和别人结合 —— 铃声相当于顶了食物原先的职位，替身文学，串位了。所以考试说『作为』，你就把它转换成『替代』的意思。」判断题看到这句 → 对。

⚠️ 拔高 2 · 老师带着推的最难一题（126:18-132:41）

题：学生进考场或老师宣布即将考试时感到焦虑，用经典条件作用的哪个来解释？（一级 / 消退 / 泛化分化 / 高级）

  1. 第一步：分 S / R。进考场、宣布考试 = 刺激（外界给的）；焦虑 = 反应（个体的）。这是「刺激 → 反应的联结」。没涉及消退（消退是切断联结、光有刺激不反应了）；没涉及泛化分化（那需要多个相似刺激，这里只有一个）。排除 B、C。
  2. 第二步：先天还是后天？「我先天进考场就焦虑吗？」后天的 → 条件反射。
  3. 第三步：往上推「跟谁结合」。「为什么进考场焦虑？如果进考场就成功，他还焦虑吗？焦虑个毛线！所以大概率是因为失败产生的焦虑。」推导：进考场 + 失败 → 焦虑 ⇒ 进考场 → 焦虑。这个「失败」相当于实验里的「铃声」。
  4. 第四步：失败是无条件刺激还是条件刺激？「失败天生就会让我焦虑吗？小孩天生失败那么多啊 —— 走路就跌倒、吃饭吃不进去，他难受了吗？没难受。」所以失败是后天有感觉的 = 条件刺激。跟条件刺激结合建立的 → 高级条件作用。选 D。

老师：「你就假定一个条件，你就推呗，你管他推失败推啥。推到失败是条件刺激，答案就出来了，再上一步都不用推了。」「小白学员一次听不明白不要紧，你自己再多捋两遍。」

老师板书（S070→S072→S098 三个阶段）

S070 左下红笔写一级类比「食→流 / 食+铃→流 / 铃→流」，题干圈①、写 S→R，B/C 斜划排除。S071 右下红笔补二级类比「铃→流 / 铃+灯→流 / 灯→流」，中间写「进考场→焦虑」，蓝绿括注「条件反射」。S072 中间紫笔写「失败→焦虑」「进考场+失败→焦虑」，圈「失败」。S098（课末回看）只剩两行「进考场+失败→焦虑 / 进考场→焦虑」，S、R 分别标在下方，答案 D 前打了大勾。

关键词
一级 = 跟无条件刺激结合高级 = 跟条件刺激结合替代性无条件刺激作为 = 替代失败 = 条件刺激
记忆锚点
看碰瓷的谁：碰食物 = 一级，碰铃声 = 高级；进考场 ← 失败 ← 后天 → 高级
出题人怎么考
判断「中性刺激一旦成为条件刺激就可以作为无条件刺激」→ 对（作为 = 替代）。单选进考场焦虑 → 高级条件作用（往上推到「失败」）。

#28T10 判别决策树例子分析两步法 + 经典 vs 操作性例子分析（S064 / S065 两组题）
一句话说人话拿到题先把「外界给的」和「个体做的」分开，再问「天生就会吗」；题目提到「操作性」大概率是要你跟经典比 —— 看谁在前。

老师给的解题模板（117:47-124:07）

两步法（S064 顶部两条提示）
  1. 关注：先天—无条件 vs 后天—条件。反问「我天生就会吗？」老师的例子：「你闻香水味也叭叭流口水吗？香水味也香啊。你一定要是闻过这个味儿、吃过、知道好吃，再闻到才流口水。为什么有的人闻榴莲流口水，有人不流？就是因为吃过觉得好吃。」→ 后天。
  2. 区分：外界—刺激 vs 个体—反应。铃声、菜香、大扇贝是外界给的 = 刺激；流口水、恶心呕吐是个体做的 = 反应。题干「问的是谁」就答谁 —— 「落脚点问的是铃声，不是分泌唾液，那你要把反应、反射排除」。
经典 vs 操作性（拔高 1，S065）

「一旦考『操作性条件反射』（斯金纳的观点，反应在前刺激在后 R→S），你第一反应是啥？他应该可以对比经典来考。那我就看他刺激在前还是反应在前。」经典性条件作用：S→R，刺激在前。解题关键写在幻灯片上：经典性条件作用的建立 = 无条件刺激/条件刺激1 + 中性刺激 → 条件反应【解题关键：S→R】。

徐文长的驴：作揖 + 鞭打 → 惊跳（×N）⇒ 作揖 → 惊跳。作揖是外界给的（刺激），惊跳是驴做的（反应）→ 刺激在前 → 经典性。「如果你整不明白它怎么建立，你就看最后一句话，你完全能做对题 —— 看刺激在前还是反应在前。」（作揖看不懂就理解为鞠躬。）

老师板书（S064 紫/红笔，S068-S069 红笔）

S064：铃声/唾液分泌下写「S→R」；炒菜香/流口水下写「S→R」；第三题红笔圈「因为」、划「呕吐」—— 题干自己说了「曾经让你呕吐过」，明摆着后天。S068：首题框「要坐汽车 / 呕吐」写 S→R 和「个体」，「操作性」下写「R→S」，右侧「vs 经典 S→R」。S069：底部两行「作揖+鞭打→惊跳 / 作揖→惊跳 XN」，驴下写「个体」，作揖到惊跳下写「外界S→…个体R」。

关键词
外界 = 刺激个体 = 反应先天 / 后天问谁答谁S→R 经典R→S 操作
记忆锚点
先分 S/R，再问天生会不会；提到操作性就比谁在前
出题人怎么考
「铃声是（ ）」→ 排除反射/反应，后天 → 条件刺激；「菜香和口水分别是」→ 条件刺激、条件反射；「坐汽车呕吐属于操作性条件反射」→ 错（刺激在前，是经典）。

判断 · 拔高2024 真题 · S065 第 1 题经典 vs 操作
小陈一坐汽车就会晕车，并伴随着强烈的呕吐；后来他一听说要坐汽车就开始呕吐。小陈的这种反应属于操作性条件反射。
  • A. 正确
  • B. 错误
老师的推导（122:59 – 124:07）「操作性条件反应是后边斯金纳的观点，强调反应在前刺激在后。一旦考这样的题，大概率是和经典对比 —— 我就看刺激在前还是反应在前。坐汽车是外在给的 → 刺激；呕吐是个体的行为 → 反应。由于坐汽车引起的，刺激在前反应在后 → 这就不是操作，应该是经典。」→ 错误。「24 年考的时候我都觉得特别简单，但好多同学没整明白 —— 这个例子没学会去分析。」板书：S→R 个体；操作性 → R→S；vs 经典 S→R。
单选 · 拔高真题 · S065 第 2 题实验过程分析
明朝的徐文长经常被叔叔无端责骂，于是他背着他人对着叔叔家的驴作揖，然后马上鞭打它。重复多次之后，驴一见他作揖，就惊跳起来。下列能解释这一现象的理论是（　）。
  • A. 观察学习
  • B. 内隐学习
  • C. 经典性条件作用
  • D. 操作性条件作用
老师的推导（124:28 – 125:36）「驴是个体。看到作揖，这不是外在给的吗？惊跳不是它个体的反应吗？作揖是刺激，惊跳是反应 → 选 C，这么快就出来了。」细化：整个过程是经典的建立 —— 每次作揖就鞭打（作揖 + 鞭打 → 惊跳，×N），重复多次后单独作揖也跳（作揖 → 惊跳）。「如果你整不明白它怎么建立，就看最后一句话 —— 刺激在前反应在后 → 经典。」（作揖看不懂就理解为鞠躬。）
单选 · 拔高S070–S073 · S098最难 · 老师完整推导
当学生进考场或者当老师宣布即将举行考试时，学生感到非常焦虑，这可用经典条件作用理论的（　）来解释。
  • A. 一级条件作用
  • B. 条件作用的消退
  • C. 刺激的泛化与分化
  • D. 高级条件作用
老师的推导（126:18 – 132:41）
  1. 分 S/R：进考场、宣布考试 = 刺激；焦虑 = 反应。强调刺激→反应的联结，没有消退（切断联结、光有刺激不反应）、没有泛化分化（没有多个相似刺激）→ 排除 B、C。
  2. 先天后天：先天进考场就焦虑吗？后天 → 条件反射。
  3. 往上推跟谁结合：为什么进考场焦虑？「进考场就成功他还焦虑吗？焦虑个毛线！」大概率是失败 → 焦虑；进考场 + 失败 → 焦虑 ⇒ 进考场 → 焦虑。
  4. 失败是条件还是无条件刺激？「小孩天生失败那么多啊，走路跌倒、吃饭吃不进，他难受了吗？没有。」→ 失败是后天有感觉的 → 条件刺激 → 跟条件刺激结合 = 高级。→ D。
「这里的失败就相当于之前的那个铃声。」板书见卡 #27。
